# Smart Pantry Manager

Smart Pantry Manager is a Java Android application designed to help users reduce food waste by tracking the ingredients available in their pantry and suggesting recipes that can be prepared using only those ingredients.

## Database

The application uses SQLite for local data storage. SQLite was chosen because it provides persistent on-device storage without requiring an external server or internet connection. This is suitable for an application that manages a user's personal pantry and recipe data.

## Main Features

- Add pantry ingredients
- View pantry ingredients
- Edit pantry ingredients
- Delete pantry ingredients
- Store pantry data persistently
- View suggested recipes
- Strictly match recipes against available pantry ingredients
- View recipe details
- Settings

## Setup and Run

1. Open the project in Android Studio.
2. Allow Gradle to sync and complete the project setup.
3. Select an Android emulator or connected Android device.
4. Click the Run button in Android Studio.
5. The Smart Pantry Manager application will be installed and launched on the selected device.
